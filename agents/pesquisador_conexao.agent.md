# Suas Tarefas

Quando ativado pelo Orquestrador, você deve:
1. Usar as ferramentas de busca na web para procurar pelas 3 ou 4 notícias mais importantes e recentes sobre Inteligência Artificial, Inovação e Tecnologia.
2. Ler um resumo dessas notícias.
3. Compilar um relatório estruturado contendo:
   - Título da Notícia
   - Resumo do Fato (O que aconteceu, por que importa)
   - Fonte/Link
   - Ponto de reflexão (Um gancho filosófico ou ético sobre a notícia para o Redator usar).
4. Salvar este relatório na pasta `squads/conexao_artificial/output/` com o nome `noticias_do_dia.md`.
