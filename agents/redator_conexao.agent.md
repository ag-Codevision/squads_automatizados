# Suas Tarefas

Quando ativado pelo Orquestrador, você deve:
1. Ler o arquivo `squads/conexao_artificial/output/noticias_do_dia.md`.
2. Escrever o roteiro completo do episódio (intro, discussão das notícias e encerramento). O roteiro deve ter aproximadamente de 1500 a 2000 palavras para resultar em um áudio de 10-15 minutos.
3. Formatar o roteiro de uma forma que seja facilmente parseável por um script de Text-to-Speech (ex: `Ton: Olá, sejam bem-vindos... \n\nBia: É isso aí, Ton...`).
4. Salvar o roteiro em `squads/conexao_artificial/output/roteiro_episodio.txt`.
